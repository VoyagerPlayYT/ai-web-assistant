## 🌟 Описание проекта

**AI Google & Web Study Assistant** — это локальный веб-сервис с современным интерфейсом (Vercel / Linear стиль), созданный для автоматизации учебной и исследовательской деятельности.

### Ключевые возможности:
1. **🔍 Умный поиск и реферирование**:
   - Обращается к официальным REST API Wikipedia и открытым поисковым индексам.
   - Мгновенно извлекает проверенные определения, исторические справки и техническую документацию с прямыми ссылками на первоисточники.
2. **📝 Автоматическое конспектирование**:
   - Принимает «сырой» текст лекции, научной статьи или главы учебника и структурирует его в тезисы, ключевые формулы и выводы.
3. **🌐 Академический и технический перевод**:
   - Выполняет перевод терминологии с сохранением инженерного контекста и дает лингвистические комментарии.
4. **🎓 Генератор тестов и самопроверки**:
   - Автоматически создает интерактивные тестовые задания с выбором ответа и подробными объяснениями для закрепления материала.
5. **📚 Личная база конспектов (Knowledge Hub)**:
   - Сохранение любого ответа в локальную базу данных SQLite в один клик.
   - Быстрый просмотр, удаление и экспорт конспектов.

## 🛠 Стек технологий

- **Backend**: FastAPI, Uvicorn, Pydantic, SQLite3
- **Frontend**: HTML5, Tailwind CSS, Marked.js (Markdown парсер), Highlight.js (подсветка синтаксиса кода), Google Inter шрифт
- **Интеграции**: Wikipedia REST API, DuckDuckGo Instant Answers API
- **Архитектура**: RESTful API с полной изоляцией модулей обработки данных

## 🚀 Быстрый запуск

### Запуск в 1 клик (Windows):
Дважды щелкните по:
```bash
start.bat
```
*(Скрипт запустит веб-сервер и автоматически откроет вкладку в вашем браузере).*

### Запуск вручную:
```bash
pip install -r requirements.txt
python -m uvicorn main:app --host 0.0.0.0 --port 8001
```
Интерфейс доступен по адресу: `http://localhost:8001` (или с любого телефона в домашней сети по `http://<IP_КОМПЬЮТЕРА>:8001`).

## 🖥 Зачем этому проекту нужен выделенный сервер 24/7?

Веб-ассистент разработан не как одноразовая вкладка, а как постоянная сетевая служба домашней экосистемы:

1. **Доступность с любого семейного устройства 24/7**:
   - Студенты и школьники семьи могут открывать ассистента с планшетов, смартфонов и ноутбуков во время подготовки домашнего задания в любой комнате, не требуя включения основного игрового/рабочего компьютера.
2. **Хостинг локальных LLM-моделей (Ollama / Llama.cpp / vLLM)**:
   - Выделенный сервер с видеокартой или мощным CPU позволяет запускать полностью автономные локальные нейросети (DeepSeek, LLaMA, Mistral, Qwen) без ограничений по токенам, абонентской платы и риска утечки персональных учебных данных во внешние облака.
3. **Фоновая индексация и парсинг учебных материалов**:
   - Сервер по расписанию может ночью индексировать PDF-учебники, конспекты и статьи (RAG — Retrieval-Augmented Generation), создавая локальную векторную базу знаний по семейной библиотеке.
